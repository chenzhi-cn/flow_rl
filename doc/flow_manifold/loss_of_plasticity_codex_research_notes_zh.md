# 持续深度学习中的可塑性丧失：供 Codex 使用的研究上下文

> 本文将本次对话整理为可独立读取的研究笔记，并合并英文解读与中文翻译中的重复内容。覆盖研究动机、具体方法、验证工具、实验结论，以及可塑性机制、奇异值定义、表征矩阵构造、stable rank 定义差异、指标选择与评估指标的全部追问。
>
> 必须区分论文实证结果、作者机制解释、对话中的辅助推导和待验证研究假设。文中的伪代码是概念级说明，不是已经测试的复现代码。

## 0. 快速读取与证据约定

### 0.1 核心结论

1. 神经网络经过长期训练，可能越来越难学习新任务，即使仍然持续获得数据和梯度。
2. 这一现象称为可塑性丧失（loss of plasticity），与灾难性遗忘有关但不相同。
3. 论文观察到三个相关变化：神经元失活或饱和、权重幅度增长、表征多样性下降。
4. 论文没有证明上述某一个因素是所有情况下唯一或占主导的原因。
5. 持续反向传播（Continual Backpropagation，CBP）在普通梯度更新之外，持续替换极少量成熟且低贡献的神经元。
6. CBP 在所测监督学习和强化学习设置中维持了更好的长期学习能力；强化学习结果使用了调优 Adam 和少量 L2 正则化。
7. “在有限实验范围内维持可塑性”不等于“已经证明可永久学习”，也不等于“已经解决遗忘”。
8. Diffusion policy、flow policy、Transformer 和 LLM 不属于本文直接验证对象。
9. 对机器人学习的启示是：除当前回报外，也应测量模型未来适应新数据和新动力学的能力。
10. 论文版 stable rank 使用累计奇异值总量，不是常用的 Frobenius/谱范数平方比，也不是 PCA 方差阈值。
11. 表征矩阵由测量样本的隐藏激活堆叠而成，依赖网络参数、数据分布和预处理；不等于权重矩阵或 Jacobian。
12. 文中主要内部诊断可分为活跃程度、权重幅度和表征维度三类，展开为五个报告项；它们不是统一的塑性分数。
13. 作者没有在正文和 Methods 中证明论文版 stable rank 优于常用定义；有关偏好弱方向的解释属于数学推断。

## 1. 论文身份与研究目标

### 1.1 基本信息

### 1.2 Motivation

传统训练通常是：初始化网络，在有限数据上训练，再冻结网络或进行少量微调。持续学习要求同一个网络长期面对变化的数据和目标。

研究问题是：

> 网络已经学习很久以后，是否仍然是一个容易训练、能够有效适应新任务的学习者？

初始训练成功不能回答这一问题。短任务序列也可能只看到正迁移，而看不到长期累积的退化。

对于机器人和强化学习，数据分布变化有两个来源：

1. 外部变化：摩擦、动力学、物体、接触条件或观测变化。
2. 内生变化：策略改变导致访问的状态、执行的动作和训练目标改变。

因此，即使环境动力学固定，也不能假设训练数据分布固定。

### 1.3 目标

[P] 在固定规模网络和有限内存约束下持续学习，避免反复丢弃整个模型。

[M] 训练过程不仅需要优化已有特征，也可能需要持续恢复或补充容易学习的新特征。

本文主要研究可塑性，不完整解决知识保留、记忆管理、迁移速度和长期资源分配等所有持续学习问题。

## 2. 关键概念与实验判据

### 2.1 可塑性与遗忘

| 概念 | 核心问题 | 典型失败表现 |
|---|---|---|
| 可塑性（plasticity） | 是否仍能有效学习当前的新知识？ | 新任务越来越难学、恢复越来越慢 |
| 灾难性遗忘（catastrophic forgetting） | 是否保留过去的有用知识？ | 旧任务性能下降 |
| 负向前向迁移（negative forward transfer） | 之前的训练是否妨碍后续学习？ | 旧网络学习新任务不如全新网络 |
| 表达能力 | 是否存在一组参数可表达目标函数？ | 架构不足以表示目标 |
| 可训练性 | 从当前参数出发能否高效达到目标？ | 架构足够，但有限预算内学不好 |

可塑性丧失不等于网络参数量减少，也不要求其理论函数类发生变化。问题可能发生在当前参数状态及其附近的优化路径。

### 2.2 如何排除“任务变难”的解释

[P] 论文采用多种控制：

- 使用难度分布相近的随机任务序列。
- 与当前阶段上从头训练的网络比较。
- 在 CIFAR-100 中持续使用全部旧类别的数据。
- 运行很长的任务序列并进行多次独立重复。
- 比较多种网络、激活函数、学习率与任务变化频率。

[D] 为方便解释，可定义：

\[
\Delta_k =
\operatorname{Acc}_{\mathrm{continual},k}
-
\operatorname{Acc}_{\mathrm{fresh},k}.
\]

- 正值表示过去训练帮助了当前阶段。
- 负值表示在当前阶段规定的训练设置和预算下，过去训练造成了劣势。

这是解释性记号，不是论文额外提出的新指标。比较时必须说明当前阶段的优化预算；持续训练模型拥有更多历史训练，这不等于两组总训练计算量相同。

## 3. 为什么会失去可塑性

### 3.1 最核心的解释

[M] 训练使网络适应已经见过的任务，但也可能使参数状态越来越不利于新目标的优化。

常规梯度更新为：

\[
\theta_{t+1}=\theta_t-\alpha\nabla_\theta L_t(\theta_t).
\]

[D] 当前损失下降并不直接奖励“未来仍然容易学习”。只要当前损失下降，导致部分特征失活、冗余或优化困难的更新也可能被接受。

这不是说专门化一定有害。任务相关时，已经学到的特征可以加速后续学习；论文的 CIFAR-100 实验也出现了先正迁移、后退化的过程。

### 3.2 神经元失活或饱和

[P] 可塑性下降伴随更多死亡或休眠单元。

考虑标量输出的一层 ReLU 网络：

\[
f(x)=\sum_i v_i\operatorname{ReLU}(w_i^\top x+b_i).
\]

[D] 对输入权重求导：

\[
\frac{\partial L}{\partial w_i}
=
\frac{\partial L}{\partial f}
v_i
\mathbf{1}[w_i^\top x+b_i>0]x.
\]

如果某个单元对当前输入一直处于不激活状态，则该通路对输入权重的梯度为零。预测误差很大，并不保证所有神经元都能获得更新。

对于 sigmoid 或 tanh，饱和也会使导数接近零。

限制：

- 样本上的失活不等于对所有可能输入永久失活。
- 输入分布和上游表征的变化可能重新激活某些单元。
- 论文在不同激活函数中都观察到退化，因此不能用 ReLU 死亡解释全部现象。
- 休眠单元的统计定义依赖阈值和测量数据分布。

### 3.3 表征冗余与低有效秩

[P] 在多个实验中，可塑性下降伴随表征秩降低。

[M] 当很多神经元产生相似特征时，网络可能缺乏能够立即支持新任务的多样表征。网络仍有足够参数，但需要更大程度地重组已有特征。

限制：

- 低秩表征不必然有害；低维特征可能恰好适合后续任务。
- 表征矩阵的秩与参数 Jacobian 的秩是不同概念。
- 不能把参数数量、表征有效秩和可塑性三者直接画等号。
- 当前低秩不意味着整个网络函数类永久丢失了表达能力。

### 3.4 权重增长与优化几何

[P] 可塑性下降常伴随平均权重绝对值增大。L2 正则化在若干实验中缓解退化。

[M] 权重增长可能与饱和、损失曲面的条件恶化和学习速度下降相关。

[D] 一个直观情形是损失曲面部分方向很陡、其他方向很平：

- 大学习率可能让陡峭方向不稳定。
- 为保持稳定而减小学习率，会使平坦方向进展缓慢。

限制：

- 大权重不必然对应差可塑性。
- 权重范数受参数化、缩放对称性和归一化影响。
- 对一般非凸网络，不能把 Hessian 条件数直接套用成全局收敛保证。
- 论文的相关性和干预实验不等于对所有网络的因果定理。

### 3.5 优化器状态也可能参与退化

[P] PPO 实验发现标准 Adam 与调优 Adam 的行为差异显著：

- 标准配置：\(\beta_1=0.9,\ \beta_2=0.999\)。
- 调优配置：\(\beta_1=\beta_2=0.99\)。

[M] 当新分布产生突然增大的梯度时，一阶与二阶矩估计的不同响应速度可能造成较大参数更新。匹配衰减系数在实验中改善了稳定性。

不能将“权重是训练过程中唯一变化的状态”推广到使用 Adam、动量、归一化统计或其他状态变量的一般系统。

### 3.6 目前能否确定主要原因

不能给出适用于所有任务和模型的单一原因排序。

最稳妥的回答是：历史训练形成的参数与优化器状态可能不利于新目标优化；失活、冗余、尺度和优化几何问题可以以不同组合出现。

CBP 同时改变多个因素，因此 CBP 有效并不能识别某个因素的独立因果贡献。

[R1] 补充研究的摘要也指出，可塑性丧失可以由多个相对独立的机制产生，处理单一机制不一定充分。本次只核对了该研究的摘要级结论，未逐项复核全文实验。

## 4. 辅助推导：局部 Jacobian 如何影响学习速度

[D] 本节是本次对话的解释性推导，不是主论文给出的统一机制定理。

### 4.1 假设与定义

考虑固定一批输入，必要时将所有输出展平为向量：

\[
f_\theta\in\mathbb R^d,\qquad
e=f_\theta-y,\qquad
J=\frac{\partial f_\theta}{\partial\theta}\in\mathbb R^{d\times p}.
\]

使用平方损失：

\[
L(\theta)=\frac12\|e\|_2^2.
\]

这里使用未归一化的求和形式；若使用样本均值，更新中会出现相应比例因子。

在普通梯度下降下：

\[
\nabla_\theta L=J^\top e,
\qquad
\Delta\theta=-\alpha J^\top e.
\]

使用一次更新内的局部线性近似：

\[
f_{\theta+\Delta\theta}\approx f_\theta+J\Delta\theta.
\]

因此：

\[
\boxed{
e_{\mathrm{new}}\approx(I-\alpha JJ^\top)e.
}
\]

### 4.2 解释

令 \(K=JJ^\top\)。在局部冻结 \(J\) 的模型下，沿 \(K\) 的特征值 \(\lambda_i\) 对应方向：

\[
e_i^{\mathrm{new}}\approx(1-\alpha\lambda_i)e_i.
\]

- 若新任务误差落在很小的 \(\lambda_i\) 对应方向，每步改善很小。
- 若 \(\lambda_i=0\)，该方向在当前一阶近似下不可调整。
- 若较大特征值限制了稳定步长，而另一些方向特征值很小，则学习速度可能不均衡。
- 误差大小本身不足以确定学习速度；还取决于误差与可调整方向的对齐关系。

这一视角有助于解释：

- 失活单元可能让部分参数导数消失。
- 不同参数对输出作用高度重复时，可能缺少有效调整方向。
- 优化器和参数化会改变实际的更新几何。

### 4.3 不可过度推断

- 这是平方损失、固定输入、小步长、普通梯度更新下的一阶分析。
- Jacobian 在真实训练中会变化，因此一阶不可达不等于永远不可达。
- Adam、PPO、交叉熵和随机小批次不能不加修改地直接套用该式。
- \(\Phi\) 表示特征，\(J\) 表示参数敏感度，二者不是同一个矩阵。
- 此推导不证明所有可塑性问题都来自低秩或梯度消失。
- 学习能力下降还可能涉及泛化、数据覆盖和优化器状态。

## 5. 具体方法：Continual Backpropagation

### 5.1 基本思想

[P] 普通反向传播在开始时随机初始化，之后持续更新同一批参数。CBP 在梯度更新之外不断引入少量新的随机特征。

\[
\text{CBP}=
\text{常规梯度学习}
+
\text{成熟低贡献单元的选择性替换}.
\]

CBP 保持网络大小固定。

### 5.2 贡献效用

对第 \(l\) 层第 \(i\) 个神经元：

\[
u_{l,i,t}
=
\eta u_{l,i,t-1}
+
(1-\eta)|h_{l,i,t}|
\sum_{k=1}^{n_{l+1}}|w_{l,i,k,t}|.
\]

其中：

- \(h_{l,i,t}\)：神经元激活。
- \(w_{l,i,k,t}\)：该神经元到下一层的输出权重。
- \(\eta\)：效用滑动平均衰减，论文使用 0.99。
- \(u_{l,i,t}\)：对当前数据的局部贡献估计。

该指标同时考虑激活大小和输出连接大小。它不是最终损失或回报层面的全局重要性，也不保证保存对罕见旧任务有用的特征。

[P] 对 mini-batch，作者指出可以使用批内平均的即时效用以节省运行平均的计算，并展示了相关比较。

### 5.3 成熟度保护

每个单元维护年龄 \(a_{l,i}\)。只有年龄超过成熟阈值 \(m\) 的单元才可以被替换。

原因：新单元的输出权重为零，初始效用也为零。保护期让它有机会先学习输出连接。

### 5.4 替换预算

设当前层有 \(n_{\mathrm{eligible}}\) 个成熟单元，替换率为 \(\rho\)，每次累积：

\[
c_l\leftarrow c_l+\rho n_{\mathrm{eligible}}.
\]

预算允许时，选择成熟单元中效用最低者进行替换，并扣除对应预算。

例子：[P] CIFAR-100 使用 \(\rho=10^{-5}\)。若一层约有 512 个合格单元，则每步期望预算增量为 0.00512，约每 200 次更新替换一个单元。

这里的“更新”不是自动等同于环境步、episode 或 epoch。

### 5.5 替换操作

对选中的单元：

\[
w_{\mathrm{in}}\sim D_{\mathrm{init}},\qquad
w_{\mathrm{out}}\leftarrow0,\qquad
u\leftarrow0,\qquad
a\leftarrow0.
\]

解释：

- 输入权重随机重置：生成新候选特征。
- 输出权重置零：避免随机新特征立即扰动下游。
- 保护期：让输出连接先学习，再使梯度进入新的输入参数。

重要限制：替换会删除旧单元的贡献，因此不严格保持网络函数不变。选择低效用单元只是降低扰动的启发式策略。

### 5.6 概念伪代码

以下省略卷积、归一化、偏置、残差路径及优化器状态处理。不是可直接执行的代码。

~~~text
initialize network parameters
for each hidden layer:
    utility = zeros(number_of_units)
    age = zeros(number_of_units)
    replacement_budget = 0

for each training update:
    run forward pass and retain needed activations
    evaluate loss
    perform the ordinary gradient update

    for each hidden layer:
        age += 1
        instantaneous_utility =
            abs(activation) * sum(abs(outgoing_weights))
        utility =
            eta * utility + (1 - eta) * instantaneous_utility

        eligible = units with age > maturity_threshold
        replacement_budget += rho * number_of(eligible)

        if replacement_budget > 1 and eligible is nonempty:
            r = eligible unit with smallest utility
            incoming_weights[r] = sample(initialization_distribution)
            outgoing_weights[r] = 0
            utility[r] = 0
            age[r] = 0
            replacement_budget -= 1
~~~

说明：

- 上述低替换率流程保持论文 Algorithm 1 中每层条件触发一次替换的表达。
- 若实现改为按整数预算一次替换多个单元，属于实现选择，必须核对作者版本并记录差异。
- 批量激活需要明确平均维度；不能把上式直接广播到任意张量布局。
- 精确的前向激活缓存时刻、参数更新时刻和实际代码行为仍需对照作者实现。

### 5.7 与其他方法的区别

| 方法 | 操作 | 可能作用 | 局限 |
|---|---|---|---|
| L2 regularization | 对大权重加惩罚 | 限制尺度增长 | 不直接产生新特征 |
| Shrink and Perturb | 权重收缩并加随机噪声 | 控制尺度并注入变化 | 也扰动高贡献参数 |
| Full reset | 重置整个网络 | 恢复全新初始化状态 | 丢弃已有结构 |
| CBP | 替换成熟低贡献单元 | 补充特征，保留大部分已有结构 | 效用启发式，存在遗忘和超参问题 |

[P] 强化学习中，报告的 CBP 结果配合少量 L2；单独 CBP 对超参数较敏感。

### 6.2 Continual ImageNet

[P] 设置：

- 使用下采样的 32 × 32 ImageNet。
- 1,000 个类别，每类 700 张图像。
- 每类 600 张训练、100 张测试。
- 每个任务选择两个类别，因此有 1,200 张训练、200 张测试图像。
- 每任务训练 250 个 epoch，batch size 100。
- 三个卷积及池化层，随后三个全连接层。
- SGD momentum 为 0.9，使用交叉熵。
- 任务切换时，将两个输出单元的输入权重重置为零。
- 算法比较持续到 5,000 个任务，主结果平均 30 次运行。
- 图 1c 的参数选择基于 5,000 个任务上的平均准确率。

[P] 结果：

- 普通反向传播初期表现较好，长期后在不同学习率下都明显退化。
- 部分配置最终接近或低于线性基线。
- L2 和 Shrink and Perturb 有帮助，CBP 在比较中表现更好。

解读限制：

- 线性模型的头就是整个模型，因此线性基线在每任务上相当于重置。
- 输出头重置利用了任务边界信息。
- 该设置主要验证塑性，不适合据此声称旧任务记忆得到了保留。
- 对若干千任务上的表现进行调参，不代表新任务族上的零调参保证。

### 6.3 类别增量 CIFAR-100

[P] 设置：

- 每次增加五个类别，从 5 到 100，共 20 个阶段。
- 每个阶段训练所有已出现类别的数据。
- 每类 450 张训练、50 张验证、100 张测试图像。
- 使用 ResNet-18、batch normalization、数据增强和 L2。
- 每阶段训练 200 个 epoch，总共 4,000 个 epoch。
- 每阶段学习率从 0.1 重启，然后按 0.02、0.004、0.0008 调度。
- 使用验证集选择阶段内最优权重，进入下一阶段前恢复该权重。
- 每阶段与同结构的从头训练网络比较。
- 主图平均 30 次运行。

[P] 结果：

- 初期持续训练优于从头训练。
- 大约超过 40 个类别后，基础系统出现明显劣势。
- 到 100 类时落后约 5 个百分点；不是相对下降 5%。
- CBP 基本消除这一劣势。
- CBP 最终准确率为 76.13%。
- 基础系统的休眠单元比例显著增长，表征秩下降更明显。

解释：

旧数据一直可用，因此不能仅归因于数据缺失造成的遗忘；这里较好地隔离了历史训练状态对后续优化的不利影响。

### 6.4 Online Permuted MNIST

[P] 设置：

- 每个任务使用不同的固定随机像素置换。
- 每任务逐个呈现 60,000 张图像，单遍训练，无 mini-batch。
- 不提供任务切换通知。
- 主要配置为三个隐藏层，每层 2,000 个单元。
- 主长序列为 800 个任务。
- 另行测试 100、1,000、10,000 单元/层等网络宽度及不同变化频率。

[P] 结果：

- 早期可能改善，随后长期退化。

限制：

论文中使用的 online normalization 不等于所有归一化方法。不能由该实验推断 LayerNorm 或所有归一化方法都损害可塑性。

### 6.5 Slowly-Changing Regression

不能将可塑性丧失完全归因于 ReLU 死亡，也不能认为它只出现在突变式任务切换。

## 7. 数学基础：表征矩阵与奇异值

### 7.1 表征矩阵的构造

[P/D] 论文测量隐藏层表征的谱；下面采用“样本为行、特征为列”的显式记法解释其构造。

固定训练时刻 \(t\) 的参数 \(\theta_t\)，第 \(l\) 层对输入 \(x\) 的输出为：

\[
h_{\theta_t}^{(l)}(x)\in\mathbb R^{d_l}.
\]

对测量样本集 \(\mathcal D_{\mathrm{probe}}=\{x_1,\ldots,x_N\}\)，定义：

\[
\boxed{
\Phi_{\theta_t}^{(l)}(\mathcal D_{\mathrm{probe}})
=
\begin{bmatrix}
h_{\theta_t}^{(l)}(x_1)^\top\\
h_{\theta_t}^{(l)}(x_2)^\top\\
\vdots\\
h_{\theta_t}^{(l)}(x_N)^\top
\end{bmatrix}
\in\mathbb R^{N\times d_l}.
}
\]

其元素满足：

\[
\Phi_{ij}^{(l)}=h_j^{(l)}(x_i).
\]

| 对象 | 含义 |
|---|---|
| 行 \(i\) | 样本 \(x_i\) 的完整隐藏表征 |
| 列 \(j\) | 神经元或特征 \(j\) 对所有测量样本的响应 |
| 元素 \(\Phi_{ij}\) | 特征 \(j\) 对样本 \(i\) 的激活值 |
| 行数 \(N\) | 测量样本数 |
| 列数 \(d_l\) | 被测隐藏层的表征维度 |

将整体矩阵转置不改变非零奇异值，也不改变本文讨论的谱指标。

重要：\(\Phi\) 是数据依赖的激活矩阵，不是网络权重矩阵，也不是 Jacobian。

### 7.2 表征冗余的最小例子

[D] 以下人为构造的例子不来自论文实验：

\[
h(x_1)=(1,2,0),\quad
h(x_2)=(2,4,0),\quad
h(x_3)=(3,6,0).
\]

因此：

\[
\Phi=
\begin{bmatrix}
1&2&0\\
2&4&0\\
3&6&0
\end{bmatrix}.
\]

- 第二列等于第一列的两倍，两个响应模式线性重复。
- 第三列为零，该单元在当前样本上未激活。
- \(\operatorname{rank}(\Phi)=1\)。

虽然有三个单元，但当前样本上的响应只有一个线性独立模式。真实数据通常只有近似依赖，所以数值谱摘要比严格代数秩更有用。

这里的“方向数”是测量样本的线性表征维度，不等于语义概念数，也不等于非线性流形的内在维度。

### 7.3 与权重矩阵的关系

[D] 若输入样本按行堆叠为 \(X\)，一个全连接 ReLU 层可写成：

\[
\Phi=\operatorname{ReLU}(XW^\top+\mathbf1b^\top).
\]

这说明：

- \(\Phi\) 同时取决于数据、权重、偏置和非线性。
- 同一个 \(W\)，在不同 \(X\) 上可能得到不同的 \(\Phi\) 谱。
- 权重秩、表征秩和参数 Jacobian 秩不是同一对象。
- 有限样本的表征秩不能直接解释成网络在所有可能输入上的表达能力。

### 7.4 论文使用哪一层、哪些样本

| 实验 | 论文明确说明的测量方式 | 尚需代码核对的细节 |
|---|---|---|
| CIFAR-100，Fig. 2d | 测量倒数第二层表征的论文版 stable rank | 具体 probe 样本、矩阵预处理和测量模式 |
| Online Permuted MNIST | 每个任务训练前随机抽取 2,000 个样本估计隐藏层 effective rank；报告平均有效秩 | 精确的层间聚合、实现口径 |
| Ant，Fig. 4 | 报告表征 stable rank 等内部指标 | 具体网络、采样窗口和预处理应核对实现 |

[P/D] MNIST 主要配置为每层 2,000 个隐藏单元，因此按上述记法，每个被测层在 2,000 个样本上可形成 \(2000\times2000\) 的矩阵。

不要把 MNIST 的采样量和任务前测量时机自动推广到所有其他实验。

### 7.5 奇异值的定义

[D；标准线性代数] 对非零实矩阵 \(A\in\mathbb R^{n\times m}\)，奇异值是 \(A^\top A\) 的特征值的非负平方根：

\[
A^\top A\,v_i=\lambda_i v_i,
\qquad
\sigma_i=\sqrt{\lambda_i}.
\]

因为：

\[
x^\top A^\top Ax=\|Ax\|_2^2\geq0,
\]

所以所有 \(\lambda_i\geq0\)。

通常列出 \(p=\min(n,m)\) 个奇异值，并降序排列：

\[
\sigma_1\geq\sigma_2\geq\cdots\geq\sigma_p\geq0.
\]

若 \(m>n\)，\(A^\top A\) 还有额外的零特征值。这里采用标准紧凑计数；原论文某些公式把奇异值索引上限写成 \(\max(n,m)\)，可通过补零理解，但实现通常使用 \(\min(n,m)\) 个返回值。

### 7.6 奇异值为何表示伸缩倍数

对单位右奇异向量 \(v_i\)：

\[
\|Av_i\|_2^2
=v_i^\top A^\top Av_i
=\lambda_i,
\]

所以：

\[
\|Av_i\|_2=\sigma_i.
\]

当 \(\sigma_i>0\)，定义 \(u_i=Av_i/\sigma_i\)，则：

\[
Av_i=\sigma_i u_i.
\]

单位输入方向 \(v_i\) 被映射到输出方向 \(u_i\)，长度乘以 \(\sigma_i\)。

例如：

\[
A=
\begin{bmatrix}
3&0\\
0&1
\end{bmatrix}
\]

将单位圆变成半轴长度为 3 和 1 的椭圆，奇异值就是 3 和 1。

奇异值分解为：

\[
A=U\Sigma V^\top.
\]

- \(V^\top\)：转换到输入的正交方向。
- \(\Sigma\)：沿这些方向伸缩。
- \(U\)：转换到输出的正交方向。

奇异值只描述伸缩强度；方向信息位于奇异向量中。

### 7.7 中心化、协方差与 PCA

原始表征矩阵、中心化表征矩阵和协方差矩阵需要区分。

设：

\[
\bar h=\frac1N\sum_i h(x_i),\qquad
\Phi_c=\Phi-\mathbf1\bar h^\top.
\]

样本协方差矩阵为：

\[
C=\frac{1}{N-1}\Phi_c^\top\Phi_c.
\]

若 \(\sigma_i(\Phi_c)\) 为中心化表征的奇异值，则：

\[
\lambda_i(C)=\frac{\sigma_i(\Phi_c)^2}{N-1}.
\]

因此，PCA 解释方差使用平方奇异值；未中心化的 \(\Phi^\top\Phi\) 不是上述样本协方差矩阵。

[P/I] 论文相关 Methods 段落没有完整交代所有表征预处理细节。本次没有审查实现这些测量的代码，不能断言所有实验都进行了中心化，也不能断言所有实验都没有中心化。

复现时需要明确：

- 使用激活前还是激活后、池化前还是池化后的表征。
- 是否中心化、逐列标准化或按样本归一化。
- 网络的 train/eval 模式、batch normalization 和 dropout 状态。
- 卷积的空间维度如何汇总。
- probe 样本分布、数量和是否跨时间固定。

这些操作会改变谱，不能无说明地添加。

## 8. 四种谱指标的定义、区别和数值例子

### 8.1 统一记号

以下令 \(\Phi\ne0\)，奇异值按降序排列。记：

\[
S_1=\sum_i\sigma_i,\qquad
S_2=\sum_i\sigma_i^2.
\]

所有指标都只依赖谱，不记录奇异向量的朝向。

### 8.2 常用 stable rank

[D；定义来源见 R2]

\[
\boxed{
\operatorname{srank}(\Phi)
=
\frac{\|\Phi\|_F^2}{\|\Phi\|_2^2}
=
\frac{S_2}{\sigma_1^2}
=
\sum_i\left(\frac{\sigma_i}{\sigma_1}\right)^2.
}
\]

含义：总平方能量相当于多少个“最强方向”的平方能量。

性质：

- 通常是实数，不需要人为阈值。
- 对非零矩阵连续变化，但不保证处处可微。
- \(1\leq\operatorname{srank}(\Phi)\leq\operatorname{rank}(\Phi)\)。
- 若有 \(k\) 个相等的非零奇异值，则值为 \(k\)。
- 若最强方向远大于其他方向，则接近 1。
- 整体非零标量缩放不改变它；逐方向或逐特征缩放通常会改变它。

### 8.3 论文中的 stable rank

[P] CIFAR-100 Methods 给出：

\[
\boxed{
r_{99}(\Phi)=
\min\left\{
k:
\frac{\sum_{i=1}^{k}\sigma_i}{S_1}>0.99
\right\}.
}
\]

含义：覆盖超过 99% 奇异值总量所需的最少方向数。

性质：

- 是整数，需要阈值。
- 使用奇异值本身，不使用平方奇异值。
- 跨阈值时可能跳变。
- 不等于代数秩，也不等于常用 stable rank。
- 不等于“解释 99% 方差所需维数”。
- 整体非零标量缩放不改变它。

若 \(\Phi_k\) 表示保留前 \(k\) 个奇异分量的截断 SVD，则该阈值还可表述为：

\[
\frac{\|\Phi-\Phi_k\|_*}{\|\Phi\|_*}<0.01,
\]

其中 \(\|\cdot\|_*\) 是奇异值总和，即核范数。此等价解释是对公式的数学展开，不是额外实验结论。

### 8.4 基于能量阈值的维数

[D] 用于比较的常见形式：

\[
k_{\mathrm{energy},99}=
\min\left\{
k:
\frac{\sum_{i=1}^{k}\sigma_i^2}{S_2}\geq0.99
\right\}.
\]

对于中心化数据，它对应 PCA 解释至少 99% 方差所需维数。

注意：上式采用 \(\geq\)，而论文版 \(r_{99}\) 写的是 \(>\)。在恰好等于阈值时，边界行为不同，代码应明确记录。

### 8.5 论文使用的 entropy effective rank

[P] Online Permuted MNIST 使用：

\[
p_i=\frac{\sigma_i}{S_1},\qquad
\boxed{
\operatorname{erank}(\Phi)=
\exp\left(-\sum_i p_i\log p_i\right).
}
\]

含义：以奇异值归一化形成分布，其熵对应的有效类别数。

约定 \(0\log0=0\)。对于非零矩阵，取值在 1 与代数秩之间。

不要把 \(p_i=\sigma_i/S_1\) 悄悄替换为 \(p_i=\sigma_i^2/S_2\)：后者是另一个谱熵指标。

### 8.6 定义对照表

| 名称 | 使用的谱量 | 归一化 | 输出 | 阈值 |
|---|---|---|---|---|
| 常用 stable rank | \(\sigma_i^2\) | 最大值 \(\sigma_1^2\) | 实数 | 无 |
| 论文 \(r_{99}\) | \(\sigma_i\) | 奇异值总和 \(S_1\) | 整数 | 0.99 |
| 99% energy rank | \(\sigma_i^2\) | 平方和 \(S_2\) | 整数 | 0.99 |
| 论文 effective rank | \(\sigma_i\) | 奇异值总和 \(S_1\) | 实数 | 无 |

[I] 建议使用明确的日志名称：

- stable_rank_frobenius_spectral
- rank99_singular_mass
- rank99_energy
- effective_rank_entropy_sigma

上述命名是本笔记的实现建议，不代表作者仓库的函数名。

### 8.7 长尾例子：同一个矩阵可以得到 1.0099 和 99

[D] 人为构造 100 个奇异值：

\[
\sigma=(10,\underbrace{0.1,\ldots,0.1}_{99\text{ 个}}).
\]

常用 stable rank：

\[
\operatorname{srank}
=
\frac{100+99\times0.01}{100}
=
1.0099.
\]

论文指标：

\[
S_1=19.9,\qquad 0.99S_1=19.701.
\]

- 前 98 个奇异值总和为 19.7，不超过阈值。
- 前 99 个总和为 19.8，超过阈值。
- 因此 \(r_{99}=99\)。

能量阈值：

\[
\frac{\sigma_1^2}{S_2}
=
\frac{100}{100.99}
\approx99.0197\%>99\%.
\]

因此 \(k_{\mathrm{energy},99}=1\)。

| 指标 | 计算结果 |
|---|---:|
| 常用 stable rank | 1.0099 |
| 论文 \(r_{99}\) | 99 |
| 99% energy rank | 1 |
| 代数秩 | 100 |

这些数值并不矛盾：平方能量高度集中，但大量小奇异值的总和仍然显著。

不能由 \(r_{99}\) 较高推断弱方向一定包含有用任务信息；弱方向也可能受噪声影响。

### 8.8 零矩阵和有限样本

[I] 对全零矩阵，上述归一化分母为零。实现应显式返回约定值或未定义标记，不要直接让 NaN 混入统计。

还应记录：

- \(\operatorname{rank}(\Phi)\leq\min(N,d_l)\)，采样量可以限制可观察秩。
- 用阈值确定数值零时，阈值与浮点精度会影响结果。
- 不同层宽度或不同采样量之间，不宜直接比较未说明归一化规则的数值。
- 论文图中的缩放显示不等于原始指标天然取值在 0–100。
- 比较两个算法时，表征预处理和 probe 分布需要一致。

## 9. 为什么论文不直接使用常用 stable rank

### 9.1 作者说明了什么

[P] 论文在 CIFAR-100 中明确给出 99% 累计奇异值定义，并引用参考文献 55；在 Online Permuted MNIST 中又使用谱熵 effective rank。

本次对正文和 Methods 的核对没有找到：

- 对常用 stable rank 与论文 \(r_{99}\) 的系统比较。
- 证明常用 stable rank 不适合衡量可塑性的定理。
- 证明 \(r_{99}\) 更能预测新任务学习能力的对照实验。

因此，不能把作者的选择解释成已经确立的优越性。

### 9.2 一个可能的数学动机

[D] 常用 stable rank 以最大奇异值平方归一化，所以最强方向增强，即使其他方向没有变弱，指标也会下降。

考虑以下人为构造的谱：

| 状态 | 谱 | 常用 stable rank | 论文 \(r_{99}\) |
|---|---|---:|---:|
| A：十个方向等强 | 十个 1 | 10 | 10 |
| B：首方向增强，其余不变 | 10，后面九个 1 | 1.09 | 10 |
| C：其余方向消失 | 10，后面九个 0 | 1 | 1 |

在这个例子里：

- 从 A 到 B，常用指标反映能量集中，\(r_{99}\) 仍显示覆盖总量需要十个方向。
- 从 B 到 C，常用指标变化很小，\(r_{99}\) 对方向数量减少更敏感。

这为使用累计阈值维数提供了一个合理解释，但它是本次对话的数学分析，不是作者明确证实的选择理由。

### 9.3 为什么常用指标的下降不一定是“误报”

[D/M] 即使其他方向仍存在，最强方向变得过强也可能恶化优化条件。因此，状态 B 的常用 stable rank 下降可能捕捉到有意义的变化。

同时，\(r_{99}\)：

- 也会受首方向增大影响，只是在上例中没有跨阈值。
- 可能对长尾噪声敏感。
- 依赖 99% 阈值，不能自动视为未来可训练性的理论边界。
- 较高不等于梯度通路活跃或任务相关方向可调整。

### 9.4 “方向分布”需要分清方向与强度

所有上述谱指标都对正交坐标变换不变。它们总结方向强度的集中程度，不包含方向朝向。

同一个奇异值谱可以对应不同奇异向量。因此：

| 研究问题 | 更直接的观察量 |
|---|---|
| 能量是否集中到最强方向 | 常用 stable rank、归一化平方谱 |
| 累计覆盖指定奇异值总量需几维 | \(r_{99}\) |
| 谱强度分布是否均匀 | effective rank、完整归一化谱 |
| 具体哪些子空间发生变化 | 奇异向量、子空间夹角等 |
| 新任务是否容易学习 | 新任务学习曲线、与任务误差对齐的优化分析 |

[I] 对机制研究，联合报告几个互补谱指标和完整谱，比选择一个指标后将其当作可塑性定义更稳妥。

## 10. 文中衡量可塑性的指标全集

### 10.1 两层证据：学习表现与内部诊断

[P] 论文没有定义统一的 plasticity score。

- 任务表现：在受控设置下判断新任务是否越来越难学。
- 内部诊断：观察与退化同步的网络变化，并辅助解释。

单个低秩、较大权重或高休眠率都不足以独立证明可塑性丧失。

### 10.2 直接反映学习结果的指标

| 实验 | 指标 | 判读方式 |
|---|---|---|
| Continual ImageNet | 新任务训练后的 held-out 测试准确率 | 难度分布相近时，随任务编号持续下降 |
| 类别增量 CIFAR-100 | 相对 fresh baseline 的准确率差 | 同阶段数据和训练预算下，持续训练从占优变为落后 |
| Online Permuted MNIST | 任务内在线预测准确率 | 后续任务的在线学习表现下降 |
| Slowly-Changing Regression | 在线平方误差的分段平均 | 跟踪变化分布的能力下降 |
| 强化学习 | 每 episode 累计回报及学习曲线 | 变化后恢复能力、长期改善能力下降 |

[D] CIFAR-100 差值可记为：

\[
\Delta_k
=
\operatorname{Acc}_{\mathrm{continual},k}
-
\operatorname{Acc}_{\mathrm{fresh},k}.
\]

它的解释依赖数据与预算控制，不是对所有任务通用的塑性标量。

[P] Slowly-Changing Regression 的平方误差按每 40,000 个样本分段平均。

RL 回报还受到探索、数据覆盖、遗忘和策略稳定性影响，不能把所有回报下降归因于可塑性。

### 10.3 三类、五个主要内部指标

按作用分三类：活跃程度、权重幅度、表征维度。按具体计算方式展开为五个常用报告项：

| 类别 | 具体指标 | 定义 | 退化时常见趋势 | 主要图 |
|---|---|---|---|---|
| 活跃程度 | 死亡单元比例 | 在全部抽样输入上激活为零的单元比例 | 上升 | Extended Data Figs. 3–4 |
| 活跃程度 | 休眠单元比例 | 很少被激活；Fig. 2 采用低于 1% 激活频率 | 上升 | Figs. 2、4 |
| 权重幅度 | 平均权重绝对值 | 所有被统计权重的绝对值取平均 | 增大 | Fig. 4、Extended Data Figs. 3–4 |
| 表征维度 | entropy effective rank | 第 8.5 节定义 | 下降 | Extended Data Figs. 3–4 |
| 表征维度 | 论文 stable rank | 第 8.3 节定义 | 下降 | Figs. 2、4 |

注意：

- “五个”是对本文主要内部报告项的展开，不是五个独立因果机制。
- 死亡与休眠是相关但不同的判据。
- 退化时的趋势不是所有算法、所有阶段均成立的定律。
- Fig. 2 的 1% 阈值不能不经核对就推广成所有代码中的统一定义。

### 10.4 死亡、休眠的显式记号

[D] 对一个有 \(d\) 个 ReLU 单元的层，测量样本为 \(x_1,\ldots,x_N\)，死亡比例可写为：

\[
D_{\mathrm{dead}}
=
\frac1d\sum_{j=1}^{d}
\mathbf1\left[h_j(x_i)=0\ \text{对所有 }i\right].
\]

对应百分比为 \(100D_{\mathrm{dead}}\%\)。

按激活频率定义休眠时，先计算：

\[
a_j=\frac1N\sum_{i=1}^{N}\mathbf1[h_j(x_i)>0],
\]

再计算：

\[
D_{\mathrm{dormant}}=
\frac1d\sum_{j=1}^{d}\mathbf1[a_j<0.01].
\]

该式解释 Fig. 2 的低频激活标准，不等于使用相对平均激活幅度的其他休眠定义，也不自动适用于 tanh 等有正负输出的激活。

[P] MNIST 的死亡单元分析在每个任务开始时使用 2,000 个随机样本。

### 10.5 平均权重幅度

\[
\overline{|w|}
=
\frac1P\sum_{j=1}^{P}|w_j|.
\]

[I] 实施时应明确统计哪些参数、是否按层平均、是否包含 bias 和 normalization 参数。参数化和逐特征尺度会影响该指标。

### 10.6 辅助诊断与未直接测量的量

[P] Extended Data Fig. 5c 比较一个训练时间段内出现的最大参数更新幅度，用于分析 Adam 的稳定性。

[P] Extended discussion 还报告：在 Continual ImageNet 的第 5,000 个任务，CBP 约用 10 个 epoch 达到较好准确率，全重置网络约需 125 个 epoch。作者将其描述为约十倍的学习速度差异。这是补充观察，不是贯穿全部实验的统一塑性指标。

[D/I] 本次对话推导的 \(JJ^\top\) 谱、任务误差对齐和 Hessian 条件分析，不应被描述为论文所有实验实际测量的主指标。

[P] CBP 的 contribution utility 是用于选择替换单元的算法内部量，不是论文统一定义的塑性分数。

### 10.7 有效结论需要哪些证据

[I] 分析时优先回答：

1. 后续任务的学习表现是否真的下降？
2. 任务难度、数据和优化预算是否可比？
3. 是否能排除旧数据缺失、分布变化和优化器差异等解释？
4. 哪些内部指标与退化同步？
5. 对某个机制进行干预后，学习表现是否改善？
6. 干预是否同时改变多个因素，因而仍无法单独识别因果来源？

## 12. 结论边界与常见误读

| 易误读表述 | 应保留的准确表述 |
|---|---|
| 深度学习不能持续学习 | 被测试的常规训练方案在多种长时设置中出现可塑性退化 |
| 主要原因已经证明是神经元死亡 | 死亡或饱和是一个直接机制，但不是唯一原因 |
| 低秩必然导致不能学习 | 低秩的影响依赖目标、数据和优化路径 |
| 大权重就是不可塑 | 权重增长是相关指标，参数化和归一化会影响解释 |
| 网络容量用完了 | 当前状态可能难训练；理论表达能力不一定改变 |
| CBP 保证函数不变 | 新随机特征初始不输出，但旧贡献被删除仍会改变函数 |
| CBP 解决了遗忘 | 当前效用不保证保留旧任务知识 |
| CBP 永久保持学习能力 | 有限实验范围内没有持续退化，不是无限时间证明 |
| 随机机制在理论上必不可少 | 论文给出实证支持，没有证明所有纯梯度方法都失败 |
| Adam、归一化、Dropout 都有害 | 某些测试设置中的结果，不是普遍结论 |
| PPO 的退化完全是塑性问题 | 也涉及遗忘、数据分布、优化器与策略稳定性 |
| 有效秩就是可塑性 | 是诊断相关量，不是完整定义 |
| 表征秩就是 Jacobian 秩 | 两者不同 |
| CBP 已验证适用于 diffusion/flow policy | 主论文未测试，仍属研究假设 |

作者强调的问题主要是优化新目标的能力下降。持续训练后的泛化能力下降与其关系尚未完全厘清，不应将两种现象自动合并。

## 13. Codex 实现与复现实验的注意事项

[I] 本节是面向后续工作的检查项，不表示已经完成实现、测试或复现。

### 13.1 实现前需要明确

1. 首先确定复现哪个设置；不要混合 CIFAR、MNIST 和 PPO 的超参数。
2. 固定代码版本、数据处理、依赖和随机种子。
3. 明确什么构成一个“单元”：MLP 神经元、卷积输出通道或其他结构。
4. 明确效用统计的 batch、空间和时间聚合维度。
5. 明确替换是否施加于 policy、value 或两者，并核对作者实现。
6. 明确偏置、normalization 参数、残差分支和优化器状态如何处理。
7. 区分 L2 正则化和 decoupled weight decay，特别是在 Adam 中不能直接当作同一更新。
8. 核对单位年龄以参数更新次数、数据样本数还是环境步计数。
9. 低效用选择必须局限于合格的成熟单元。
10. 不要将同一效用规则直接套用于完全不同的结构而不解释。

### 13.2 优化器状态

[I] 重置参数后，已有动量或 Adam 矩估计可能继续影响该参数。实现必须明确是否同步重置对应状态。

本文没有审查作者代码，不能声称其具体处理方式。对 Adam 的全张量 step 计数与局部参数重置还需额外注意，不能简单推定逐元素清零就是精确复现。

### 13.3 最低限度的对照和记录

[I] 为区分收益来源，按实验目的考虑：

- 不加任何塑性干预的 baseline。
- 同预算或明确预算规则的 fresh/reset baseline。
- L2 baseline。
- CBP，或论文在 RL 中采用的 CBP + L2。
- 相同优化器调优条件下的对照。
- 学习曲线、每任务/阶段表现、休眠比例、权重幅度、表征秩。
- 任务边界、环境变化时间和总梯度更新数。
- 多个随机种子及不确定性估计。

选择哪几个对照应由具体假设决定；本文没有在当前会话中运行任何实验。

### 13.4 避免无效结论

- 单个最终回报不能证明保留了可塑性。
- 只展示前几个任务不能排除长期下降。
- 两组使用不同 Adam 参数时，不能把全部差异归因于 CBP。
- 全网重置和选择性重置可能具有不同的信息与计算预算，必须说明。
- 死亡比例下降本身不证明新任务适应能力上升。
- 在一组新任务上成功不证明旧任务记忆被保存。

## 14. 与机器人和生成式策略研究的联系

### 14.1 对机器人学习的直接启示

[P/M] 论文机器人仿真结果说明，长期学习能力值得作为独立评估目标；固定环境也可能产生不断变化的学习分布。

[I] 可以记录：

- 受控动力学变化后的恢复速度。
- 旧网络与新初始化网络在相同新数据上的适应差异。
- 策略和价值网络各自的内部指标。
- 行为回报与表征诊断之间是否存在一致关系。

### 14.2 Diffusion / flow policy：待验证假设

[H] CBP 或类似特征更新机制可能有助于生成式策略的长期 RL 优化，但本论文没有验证这一点。

需要额外考虑：

- 单元贡献可能依赖观测条件、任务条件和噪声/流时间。
- 对常见条件贡献小，不代表对稀有条件或关键接触阶段无用。
- 重置可能影响已学动作分布、时间一致性或控制稳定性。
- 策略网络和 critic 的塑性问题可能不同，需要分别测量和干预。

仅保持单元活跃或表征秩较高，并不能保证动作流形遵循、策略安全或 Q 函数估计准确。它们应作为不同假设分别验证。
